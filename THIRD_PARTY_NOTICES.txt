WOK CLIENT AND CRANKSHAFT

  ee43dee847ece639b7e5b6e9b8f6dc1729af90bd
  https://github.com/KraXen72/crankshaft/tree/ee43dee847ece639b7e5b6e9b8f6dc1729af90bd

Crankshaft and this modified source are licensed under GNU GPL version 3 only.
The complete license is in LICENSE. Upstream attribution and contributor history
are preserved in Git, README.md, and CHANGELOG.md.

WOK modifications dated 2026-07-30 include branding and application identity,
hardware-adaptive graphics selection and recovery, calibration and diagnostics,
Competitive mode, safer configuration migration and IPC/request validation,
terms-sensitive defaults, cross-platform source and tag-release CI, packaging
changes, and removal of the userscript subsystem. See the top WOK Client entry
in CHANGELOG.md.

DISCORD LOCAL RPC

src/discord-rpc.ts is an in-tree WOK Client implementation of Discord's local
RPC framing and SET_ACTIVITY request. Protocol reference:
  https://discord.com/developers/docs/topics/rpc

The previously used @nyabsi/minimal-discord-rpc npm package is not a dependency
and is not redistributed. Its package metadata declared GPL-3.0 while its
included license file contained AGPL-3.0 text; removing it avoids relying on that
ambiguous declaration.
