WOK CLIENT AND CRANKSHAFT

WOK Client 1.0.0 is the first WOK release and is a modified version of
Crankshaft 2.0.1 at commit:
  c1f1ce39e49296735ac73737b1cb6f2b5e5482b2
  https://github.com/KraXen72/crankshaft/tree/c1f1ce39e49296735ac73737b1cb6f2b5e5482b2

Crankshaft and this modified source are licensed under GNU GPL version 3 only.
The complete license is in LICENSE. During packaging, Electron Forge copies
that file into the application's resources directory as
WOK-CLIENT-GPL-3.0.txt. This release-facing copy does not replace Electron's
own license files. Upstream attribution and contributor history are preserved
in Git, README.md, and CHANGELOG.md.

WOK modifications dated 2026-08-02 include branding and application identity,
hardware-adaptive graphics selection and recovery, calibration and diagnostics,
startup and gameplay-readiness instrumentation, the launch-intro handoff,
Competitive mode, safer configuration migration and IPC/request validation,
terms-sensitive defaults, cross-platform source and tag-release CI, packaging
changes, removal of the userscript subsystem, and an attested offline runtime
laboratory. The runtime laboratory source is excluded from the packaged
Electron application. See the top WOK Client entry in CHANGELOG.md.

DISCORD LOCAL RPC

src/discord-rpc.ts is an in-tree WOK Client implementation of Discord's local
RPC framing and SET_ACTIVITY request. Protocol reference:
  https://discord.com/developers/docs/topics/rpc

The previously used @nyabsi/minimal-discord-rpc npm package is not a dependency
and is not redistributed. Its package metadata declared GPL-3.0 while its
included license file contained AGPL-3.0 text; removing it avoids relying on
that ambiguous declaration.

EXTERNAL OFFLINE-RUNTIME TOOLS

PresentMon is not bundled with WOK Client. Runtime-tournament operators supply
an external PresentMon executable, and the mandatory content-addressed dry-run
report attests its exact binary identity before offline ETL replay.

PresentMon: MIT
  https://github.com/GameTechDev/PresentMon

The dedicated WOK ETL recorder is also not part of the packaged Electron
application. The dry-run report attests its exact binary identity before use.
The controller source inventory separately attests the recorder source, project
bytes, and the exact PresentMon 2.5.1 source patch required by the recorder.
That source inventory is not represented as source-to-binary build provenance.
The obsolete live-PresentMon capture/preflight path is not part of the current
ETL-recording and offline-PresentMon-replay architecture.
