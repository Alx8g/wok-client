The attached WOK_ELECTRON_SOURCE.patch implements:
  - Windows High priority for only the Network Service utility process
  - a dedicated WebSocket I/O queue with one control-priority task service
  - a separately gated posted-message queue with one control-priority task
    service
  - unchanged input and compositor queue priorities

Current WOK builds enable only Network Service High priority. The WebSocket and
posted-message scheduler experiments remain present but disabled after packaged
runtime smoke testing failed when they were activated.

The runtime uses Chromium's base uncapped draw-throttle condition. It does not
ship the later depth-one uncapped compositor back-pressure experiment. The
source patch, runtime audit and checksum manifest are assets on the runtime
release above.

Validation completed before release:
  - ZIP integrity for all 73 entries
  - only electron.exe differs from the preserved optimized runtime payload
  - focused scheduler tests passed 4/4
  - a clean three-cycle comparison covered nine runtime treatments
  - the user accepted the isolated WOK preview after live gameplay ping/FPS
    testing

The clean fixed-load matrix measured a 2,916 median requestAnimationFrame
callback rate for the final all-escapes candidate. These callback measurements
do not establish submitted, GPU-completed, presented or displayed frame rates.
Performance varies by hardware, drivers, thermals, game updates and scene.

Local Forge and Windows release builds select this archive through
WOK_QUALIFIED_ELECTRON_ZIP. forge.config.ts verifies the pinned SHA-256, stages
the standard Electron archive name on the same volume, and passes that
directory to Electron Packager through electronZipDir.

Linux x64 and macOS arm64 releases continue to use the default patched Electron

DOWNLOAD VERIFICATION

pnpm-workspace.yaml disables electron-nightly's automatic dependency build.
The root postinstall command runs scripts/install-electron.mjs, which supplies
the patched nightly mirror and enables remote checksums before invoking
Electron's installer. When its release marker is absent, the helper removes any
same-version Electron payload first so an official nightly cannot be mistaken
for the patched build. The installer then downloads SHASUMS256.txt from the same
release and verifies the selected archive. forge.config.ts uses the same mirror
without disabling Electron Packager checksum validation.

A checksum confirms the downloaded archive matches the release asset. It is not
proof that the binary is reproducible from the referenced source commit. Review
the source comparison and build provenance before distributing executable
artifacts. Public WOK Client release jobs are tag-only, publish checksums, and label unsigned cross-platform binaries as prereleases with native-test limitations.
